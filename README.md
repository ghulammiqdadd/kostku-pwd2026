
# KostKu
### Sistem Manajemen dan Booking Rumah Kos Berbasis Web

KostKu merupakan aplikasi berbasis web yang dirancang untuk membantu pemilik kos dalam mengelola properti, kamar, penyewa, pemesanan, tagihan, dan pembayaran secara terintegrasi.

## Informasi Proyek

- Mata Kuliah: Pemrograman Web Dinamis 2026
- Nama Proyek: KostKu
- Kompleksitas: Kompleks
- Arsitektur: Monorepo

## Teknologi

**Backend**
- PHP 8.3
- Laravel 13
- REST API
- JWT Authentication

**Frontend**
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4

**Database**
- Supabase PostgreSQL

## Role Pengguna

1. Admin
2. Pemilik Kos
3. Penyewa

## Fitur Utama

- Authentication dan Role Management
- Dashboard
- Manajemen Properti
- Manajemen Kamar
- Booking Kamar
- Manajemen Penyewa
- Kontrak Sewa
- Tagihan dan Pembayaran
- Pengaduan
- Laporan Transaksi
- Audit Log
